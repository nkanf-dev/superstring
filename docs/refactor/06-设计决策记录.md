# 设计决策记录

> 本页是 2026-09-25 重构方案选择的依据。**用户明确方向**与**本轮工程选择**分开标记；后者是待评审的实施依据，不冒充现有代码事实。每条遵循“现状 → 改动 → 预期/代价”。[源代码地图](/Users/nkanf/docs/superstring/06-代码地图与项目全貌.md)

## 用户已确定的方向

1. Agent 是系统中心；所有需模型推理的工作由统一抽象运行，轻量 Agent 可单轮完成。[现状/目标图](./01-架构决策与现状目标对照.md)
2. Web 和 OneBot 私聊/群聊共用主 Agent Loop；以会话拓扑表达直接对话和共享群聊，OneBot 是平台适配器。
3. 记忆/知识可替换摄入、维护与消费策略，但不照搬当前细碎流程做必经 Provider 层；现有能力不降级。
4. 本轮只为工具/Skills/MCP、Agent 间上下文复用留简单接口；不实现这些未来功能。`ContextHandle` 只暴露读出口。
5. 避免大而全 `HarnessPolicy`、重复防御检查与硬编码产品边界；保持必要授权与外部效果一致性。PR 数量尽量少，方案定为 3 个代码 PR，并把前端迁移纳入。

## 重要状态与不变量

- `ConversationEvent` 是接入后的事实，平台 ID 去重、本地 `seq` 排序；原始用户消息不可因 wake 合并被覆盖。`addressing` 保存 @、回复已发消息、私聊、Web 请求等理由和目标。
- 同一会话同时最多一个主 run；`leaf` 不占该会话执行锁。run 的 `observedThroughSeq` 只能在终态事务内推进，不能跨越没读过的入站事件。
- 模型草稿不是外部发送许可。`CommittedOutputIntent` 写入前核对运行所有权、目标、授权、相关会话变化；写入后不再重新生成相同意图。`sending/unknown` 不自动重放。
- 资料证据必须有来源/版本/作用域；知识撤权立即阻止新查询和精确上下文查看。QQ 原文、媒体描述及复制到运行记录的文本共同受原保留期约束。
- Web SSE `done` 表示完成文本已提交；浏览器看到的 partial 不能被事后改写成成功。
