Web 的稳定关联：`prepareTurn` 已按 `(sessionId,clientRequestId)` 识别旧 turn，并给出待写 assistant `messageId`。[当前 prepare](/Users/nkanf/clones/superstring/src/server/services/direct-service.ts:97) 新 run 用 `owner_kind=web_turn, owner_id=turn.id`；Web `StreamSession.outputId` 取该 turn 预留的 assistant message ID。同请求重试先经旧 turn 幂等约束找到它，再读该 owner 的最新/活动 run。PR 2 对 `(owner_kind,owner_id,started_at)` 建查询索引，并以旧 turn 租约/生成 token 保证同一请求只有一个活动生成者；不另复制 Web 正文。

## 2. 旧库升级顺序与失败恢复

1. PR 1 加 `0039` 并通过 `schema-gate`；对新任务写 run/step/context，旧对话链照常服务。只切换已迁移的后台模型调用，不双跑同一个整理任务。
2. PR 2 在数据库副本上先验证 `0040/0041`：Web 会话固定既有 agentId；OneBot 逻辑会话键包含 `channel/account/peer/agentId/bindingEpoch`。同一群/私聊改绑另一个 Agent 时建立新逻辑会话与游标，旧 Agent 历史不自动并入新 Agent；若产品将来要继承，须显式授权/迁移。`source_kind/source_id` 精确到 Web `messages` 每条 user/assistant 消息、QQ inbound `qq_events`、QQ confirmed outbound 发送或 `qq_speech_log`；同一次已确认发言若同时出现在发送账本与 speech log，只建一个引用，优先带平台回执的发送记录；旧 unknown 不伪造为助手发言。历史事件按源内顺序与时间排序，同秒跨源以固定来源优先级和原表主键打破平局，然后分配从 1 开始的本地 seq，回填同一旧库重复执行须得到同一顺序。QQ 清理过的正文只保留原有元数据，不能借回填复活。新入站的来源写入与引用分配同事务；同一平台事件重复到达不得再分配 seq。
3. PR 2 切 Web/direct 的新 run。服务启动先修复过期模型 lease：无外部意图的任务可重新运行；`planned` 出站按稳定 ID 领取，但先核 `deliver_by`、目标/授权及相关新消息，过时则标 `stale` 并新建 wake；`sending` 改 `unknown` 等对账。切换后禁止新旧主链同时对同一会话消费。
4. PR 3 群聊切换：读取旧未完成即时/主动候选，将**尚未处理的机会**映射为 wake（消息本身已有原来源）；记录转换水位；先验证无重复 Agent 输出，再停止旧 QQ 循环和候选写入。旧候选表只作为升级前历史/诊断，确认无引用后后续版本再物理删表。
5. 运行中的版本升级先停旧 worker，备份数据库和媒体私有目录，再运行 schema gate/回填，再启动新 worker。现有 schema gate 是严格前向迁移；旧二进制未必能打开新 schema，**回滚需要恢复升级前的备份**，不能只换回旧可执行文件。备份/恢复演练是合并门槛。

`context_snapshots`、`agent_steps/run_events`、**群聊/私聊压缩摘要、证据缓存、动作观察**中只要含有来源原文或媒体描述，都跟随所覆盖来源的最短到期时间与撤权清理；QQ 的 14 天正文/媒体规则必须覆盖所有派生正文。[QQ 保留期](/Users/nkanf/clones/superstring/src/server/services/qq-retention.ts:1) 来源到期后删除或重算不含该来源的摘要，不能借压缩永久保留原文。Web 摘要跟随其既有历史删除/保留语义。清理后保留状态、用量、来源 ID 及脱敏布局；`inspect` 不再返回 exact。对已删除来源的纯引用事件可保留 tombstone 供序列连续性；不可通过 action 结果或诊断再复原正文。

**对照方法**：取一套不含凭据的固定旧库副本与可复现 Web/OneBot 事件序列，先跑旧版记录输入、输出、触发时机、来源选择、预算和投递状态；在升级副本上跑新版比较。LLM 文本不要求字面相同，要求路由/授权/消息覆盖/输出目标/状态不丢，并用人工评估语义质量与延迟。对确定性部分（游标、去重、状态、授权、迁移）做自动回归；对模型质量和 UI 做带样例的人工/设备验证，不能用单元测试声称真实 OneBot/NapCat 或视觉体验通过。
