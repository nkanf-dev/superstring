> **目标：** 将当前分散的 Web/QQ/后台模型调用迁成统一 AgentRuntime、同一会话 Agent Loop 和前端运行体验，保留既有功能。方案基线 `d3167e4`；此页是未来代码 PR 的施工图，**尚未修改源码**。[工程决策](./06-设计决策记录.md) · [验收与迁移](./08-迁移与验收.md)

## 1. 当前代码落点与目标目录

当前 `src/server/services/` 同时容纳应用入口、ContextBuilder、QQ 调度、提示词、媒体、记忆和知识；`src/server/llm/` 提供文本及视觉连接；`src/server/db/` 含成熟资料和 QQ 仓储；`src/web/` 由 App + 大 store + feature 页面构成。[完整当前代码地图](/Users/nkanf/docs/superstring/06-代码地图与项目全貌.md)

目标只为**真正拥有不同职责**的边界建目录，资料内部现有实现可留原位逐步搬迁，不要求文件树与每个接口一一对应：

## 5. 新查询 API 与旧协议并存

[`src/server/app.ts`](/Users/nkanf/clones/superstring/src/server/app.ts:56) 在 PR 1 挂 `runs.ts` 的 leaf 查询，PR 2 挂 `chat-v2.ts/conversations.ts/runs.ts/deliveries.ts`，PR 3 启用 shared 列表；只增加路由，不改旧 `/chat` 的 strict SSE schema。[当前 strict 合同](/Users/nkanf/clones/superstring/src/shared/contracts/chat.ts:35)

| API（目标） | 返回/权限/分页 | 前端用途 |
| --- | --- | --- |
| `POST /v2/chat` | 原 `ChatRequest` 输入；eager JSON 错误在 SSE 前；新 SSE 公共 `{runId,conversationId,seq,at,type}`，`start` 含 runId。 | 新 Web 聊天。旧 `POST /chat` 保留原帧与严格解析。 |
| `GET /v2/runs/by-request?sessionId=&clientRequestId=` | 只在所属 Web 会话查到该请求的 run 或明确无记录；返回 runId/status/messageId。 | SSE 在首帧前断开时对账，不盲重发。 |
| `GET /v2/conversations?cursor=&limit=` | 只列当前主体可见的 Web/已绑定 OneBot 会话，返回 topology/channel/Agent/最新摘要元数据；游标分页。 | 统一会话列表。 |
| `GET /v2/conversations/:id/events?afterSeq=&limit=` | 来源按原授权/保留期投影，按本地 seq 增量分页；过期正文为 tombstone。 | Web/OneBot 只读时间线，不要求新推送设施。 |
| `GET /v2/runs/:id`、`GET /v2/runs/:id/events?afterSeq=` | 运行所有者可读终态、步骤元数据、输出摘要与事件序列；`GET /v2/runs?ownerKind=&ownerId=` 查 leaf 任务的尝试运行。 | 断流对账、运行详情、记忆/知识任务关联。 |
| `GET /v2/runs/:id/context/:stepId` | `inspect(handle,principal)`；精确/过期/撤权三态，不把原文塞在 SSE。 | 高级上下文诊断。 |
| `GET /v2/deliveries/:outputId` | 按会话绑定/Agent 授权返回 OneBot 消息与各部件 `planned/confirmed/failed/unknown/stale`；run 完成后仍可变化。 | 送达详情；不能把 run `completed` 当成“已送达”。 |

可见会话在前端窗口可见时用 `afterSeq` 和输出 ID 增量刷新（间隔可配置并与 QQ 唤醒轮询分开），隐藏时暂停；诊断页按需拉取 run/ContextHandle，送达状态按需或在活动页刷新。`RunEvent` 终态只代表 Agent run，OneBot 送达是另一个查询对象。API 端校验当前会话归属、OneBot 绑定代际、资料授权与保留期；句柄只是地址，不是 bearer token。[权限决策](./06-设计决策记录.md)

## 6. 删除与不新增清单

- **最终删除** Web 的模型直连生成、QQ 判断→回复→复核固定链、按候选再做的另一套上下文拼接、重复 preflight/全量重复校验；具体删除以调用图已无引用和验收通过为准。
- **保留** OneBot 11 协议/连接、媒体/贴图实际处理、SQLite 记忆/知识已有表和原始来源、Web 现有设置/数据治理/聊天能力、QQ 方案参数（迁移为会话/AgentSpec 配置）。
- **扩展出口** `ModelPort` 留成熟模型库/协议适配 TODO；后续独立 PR 可接入 Pi 等成熟多模型库，详见[标准协议扩展](./10-后续标准协议扩展.md)。
- **不新增** `HarnessPolicy` 总管、`SkillProvider`、MCP/外部工具运行时、强制的 `Chunker/Indexer/Ranker` 插件梯子、第二个 QQ AgentRuntime、独立消息队列基础设施。
